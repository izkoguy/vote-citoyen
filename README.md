# Vote Citoyen

Projet statique de démonstration d'un parcours de vote citoyen : Accueil → Connexion → Vote → Résultat.

## Fichiers

- `index.html` — Page d'accueil
- `connexion.html` — Formulaire de connexion simulé
- `vote.html` — Interface de vote (3 options fixes)
- `resultat.html` — Résultat prédéfini
- `style.css` — Styles globaux et responsive
- `script.js` — Interactions simulées (redirections, validation)
- `references/` — Images de référence visuelle

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune dépendance externe, aucun serveur requis.

## Parcours

1. Accueil (`index.html`)
2. Connexion (`connexion.html`) — validation côté client
3. Vote (`vote.html`) — sélection d'une option
4. Résultat (`resultat.html`) — affichage fixe
